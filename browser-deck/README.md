# Фронтенд. Интерфейсы для людей

Браузерная презентация Егора Антонова. Семь слайдов, плавные переходы, без интерактивных демонстраций и внешних зависимостей.

## Открыть

Можно просто открыть `dist/index.html` в браузере. Интернет для показа не нужен: изображения и логотипы лежат рядом. Внешних ссылок в показе нет; источники сохранены в данных слайдов.

Для локального сервера:

```sh
npm start
```

Откройте http://127.0.0.1:4173. Установка пакетов не нужна. Требуется Node.js.

## Управление

- Стрелки влево/вправо, Page Up / Page Down, пробел — переключение слайдов.
- Home / End — первый / последний слайд.
- F — полный экран (если разрешён браузером).
- На телефоне можно листать горизонтальным свайпом.

Нажимать на содержимое слайдов не требуется. Элементы появляются автоматически при переходе. При системной настройке уменьшения движения анимации отключаются.

## Редактировать

- `dist/slides.js` — тексты, заметки, источники и данные слайдов.
- `dist/app.js` — разметка, навигация и управление показом.
- `dist/styles.css` — оформление, адаптивность, переходы и печать.
- `dist/assets/` — локальные изображения и логотипы.

Проверка JavaScript: `npm run check`.

Сведения о хакатоне проверены 10 октября 2026 года. Перед будущими выступлениями актуализируйте сроки в `slides.js`. Ссылки на источники сохранены в данных соответствующих слайдов в `slides.js`.

## Один HTML-файл

Для выступления можно собрать автономный файл со встроенными изображениями:

```sh
npm run export
```

Результат: `frontend-talk.html` в папке проекта. Откройте его в обычном браузере.
